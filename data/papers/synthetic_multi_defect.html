Experimental Setup (claims this code deliberately contradicts)

We evaluate a linear classifier on a held-out test split. All hyperparameter selection is performed on a validation split; the test set is touched exactly once, for final reporting.

To account for variance from random initialization and train/test shuffling, we report classification performance averaged over 5 random seeds (mean ± standard deviation).

We report the macro-averaged F1 score as our primary metric, computed on the held-out test set only, after training is complete.
